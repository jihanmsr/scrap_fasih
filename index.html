Cara mengisi tindak lanjut lewat CSV
Klik untuk lihat panduan ▾
  1. Klik Unduh CSV — file akan tersimpan di folder Downloads
  2. Buka file CSV di Microsoft Excel:
    • Klik 2x file → pilih Delimited → centang Comma → Finish
    • Atau: di Excel, Data → From Text/CSV → pilih file
  3. Edit kolom J (Tindak Lanjut) dan/atau kolom K (Status: 1=Belum, 2=Diproses, 3=Selesai)
  4. ⚠️ Jangan ubah kolom lain terutama kolom A (ID)!
  5. Simpan sebagai CSV UTF-8: File → Save As → pilih "CSV UTF-8 (Comma delimited)"
  6. Klik Upload CSV di dashboard — sistem otomatis skip baris yang tidak diisi
💡 Aman: Baris yang kamu tidak isi/ubah tidak akan menimpa isian orang lain. Sistem hanya update baris yang kamu ubah.
